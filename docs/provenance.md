# Provenance

Marginfield was created on September 23, 2026 as a **new Git repository** from the Folune source snapshot (`dd3af3c`). Folune began on September 22, 2026. The new repository does not contain Folune's Git history and does not import native Twine source code. Its reading concept and monochrome visual direction were inspired by Twine; this is disclosed rather than presented as a wholly unrelated invention.

The two-page raster mark and book-and-cup sample illustration were AI-generated during the Folune work. The standalone mark has no embedded former product name and is reused with new Marginfield typography. The prior name-bearing concept and screenshots are not part of the active Marginfield release. A legal trademark search and final vector master remain outside this build.

Sample articles and briefings are original fictional demonstration content. Preview UI does not represent live publisher imports, OpenAI output, or emails. The official project-local hackathon skill came from https://github.com/get-convex/convex-hackathon-skill under its included MIT license. Third-party packages retain their own licenses. No license for Marginfield's own source is asserted or added.
