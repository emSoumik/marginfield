# Marginfield — hackathon scope

Started 2026-09-22. Fresh React/TypeScript/Vite application, not a Twine port. Reuses the name-free two-page mark selected during the Folune source work. The earlier native fork was moved to task-owned reference storage and no Kotlin source/history was imported here. Visual inspiration and AI-generated assets are disclosed separately.

Audience: independent designers and founders. Core flow: save public article or forward newsletter, see extraction status, select sources, generate a source-linked briefing, read originals/bookmark, explicitly request digest delivery. Three primary views: Inbox, Briefings, Reader. Responsive desktop and mobile. Convex is the production source of truth; preview mode is labelled and never impersonates working sponsor calls.

Not in scope: native parity, RSS provider sync, offline cross-device synchronization, podcasts, TTS, a shop, social feed, automatic email campaigns. No public deployment/repository/social post/submission without explicit authorization. Fresh project status is evidence, not a guarantee of eligibility; disclose reused visual direction and confirm with organizers if needed.
